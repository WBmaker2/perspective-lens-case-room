# Perspective Lens Case Room Design System

## 목적

초등학교 5~6학년이 국어 관점 비교 활동을 읽고 조작하는 동안, 지금 해야 할 행동과 그 근거를 먼저 볼 수 있게 한다. 기존 종이·잉크·청록·주황 팔레트와 라이트 모드를 유지하며 장식보다 읽기 폭, 상태 구분, 키보드 조작을 우선한다.

## 교육 맥락

- 대상: 초등 5~6학년, 한국어, 30~40분 활동
- 핵심 흐름: 사건 접수 → 렌즈 A/B → 근거 보드 → 교차 조사 → 관점 전환 → 사건 보고서
- 학습 표현: 사실·추론·평가를 구분하고, 두 관점을 참·거짓으로 승부하지 않는다.
- 안전: 모든 사건과 인물은 가상이며 학생 이름·실제 갈등·외부 전송을 사용하지 않는다.

## 색상 토큰

| 토큰 | 값 | 사용 |
| --- | --- | --- |
| `--color-paper` | `#f7f4ee` | 전체 라이트 배경 |
| `--color-surface` | `#fffdf8` | 카드·선택지·입력 표면 |
| `--color-ink` / `--color-navy` | `#233044` | 본문·제목 |
| `--color-muted` | `#667085` | 보조 설명·비활성 |
| `--color-line` | `#d8d4cb` | 기본 경계 |
| `--color-soft` | `#eeebe4` | 약한 구분선 |
| `--color-teal-dark` | `#0f766e` | 행동·완료·선택 |
| `--color-orange-dark` | `#c2410c` | 현재 행동 안내·번호·포커스 보조 |
| `--color-focus` | `#f59e0b` | `:focus-visible` 윤곽선 |

상태는 색상만으로 표현하지 않는다. 선택/완료는 텍스트와 `aria-pressed`·`data-complete`·테두리를 함께 사용하고, 오류/재검토는 메시지와 왼쪽 경계를 함께 사용한다.

## 글자와 읽기 폭

- 본문 선택값: 18px `작게`, 20px `보통`, 22px `크게`
- 줄 간격 선택값: 1.6 `촘촘하게`, 1.8 `넉넉하게`, 2 `아주 넉넉하게`
- 기본 읽기 폭: 68ch, 좁은 폭: 48ch
- 제목: `clamp(2rem, 5vw, 3rem)` 범위에서 화면 폭에 맞춰 축소
- 문장·선택지에는 충분한 줄 간격과 `overflow-wrap: anywhere`를 적용한다.

## 간격·표면

- 기본 단위는 0.5rem이며 섹션 간 1.5~2.5rem, 카드 내부 0.75~1rem을 사용한다.
- 카드 표면은 `--color-surface`, 1px `--color-line`, 작은 반경을 기본으로 한다.
- 학습 단계·주요 영역은 2px 잉크 경계로 시작해 화면 위계를 만든다.
- CTA는 진한 잉크 pill, 보조 도구는 투명 pill, 선택지는 직사각형 카드로 구분한다.

## 상태와 행동

- `현재`: `aria-current="step"`, 청록 하단 경계, 진한 제목
- `완료`: `data-complete="true"`, 완료 텍스트 또는 체크 아이콘, 청록 경계
- `선택됨`: `aria-pressed="true"` 또는 checked 라디오/체크박스, 청록 표면
- `비활성`: 회색 표면과 disabled 상태, 다음 행동 안내로 이유를 설명
- `재검토`: 주황 경계와 짧은 한국어 피드백
- 단계별 필수 CTA 하나만 `.gi-pulse`; 토글·도구·보조 버튼에는 적용하지 않는다.

## 접근성

- 모든 핵심 조작은 최소 44×44px이다.
- 키보드 순서는 화면 읽기 순서와 같고, 모든 포커스는 `:focus-visible` 3px 주황 윤곽선으로 보인다.
- 모바일 렌즈 탭은 `role="tablist"`·`role="tab"`·`role="tabpanel"`과 화살표 이동을 유지한다.
- 진행·피드백은 `role="status"`/`aria-live="polite"`를 사용하되 같은 안내를 중복 출력하지 않는다.
- `prefers-reduced-motion: reduce`에서는 애니메이션과 전환을 끄고 3px 청록 정적 윤곽선과 텍스트 안내를 유지한다.
- VoiceOver 승인이나 실제 보조공학 완료를 이 문서의 증거로 삼지 않는다.

## 반응형 규칙

- 761px 이상: 렌즈 두 패널과 비교 선택지를 나란히 보인다.
- 760px 이하: 단계 콘텐츠를 단일 열로 바꾸고 렌즈는 탭으로 전환한다.
- 480px 이하: 사건·가설·작업 블록·CTA를 세로로 배치하고 긴 버튼 이름을 줄바꿈 허용한다.
- 375px·640px: 고정 학습 도구의 safe-area와 하단 여백을 예약하며 현재 CTA와 겹치지 않는다.
- 가로 스크롤은 허용하지 않고 카드 안 긴 문장은 줄바꿈한다.

## 콘텐츠와 자산

- 화면 문구는 행동을 먼저 말하고, 내부 ID·시스템 토큰·미확인 승인 표현을 노출하지 않는다.
- `CaseIllustration` 인라인 SVG와 `public/favicon.svg`는 사건 맥락·정체성을 전달하는 기존 자산으로 유지한다.
- 일반 장식 이미지를 새로 추가할 때만 대상 학년·학습 역할·비율을 포함한 생성 안전 검토를 거치며, 사실·지도·차트·스크린샷은 자동 생성·교체하지 않는다.

## 컴포넌트 규칙

- `StageStatus`: 앱 셸에서 한 번만 렌더링하며 현재 단계와 다음 행동을 짧게 보여 준다.
- `ProgressSteps`: 단계 순서와 완료/현재 상태만 표현하고 클릭으로 상태를 임의 변경하지 않는다.
- `StageActionButton`: 게이트가 충족될 때만 pulse와 행동 안내를 노출한다.
- `SentenceCard`: 서술자 이름과 문장 번호를 접근 가능한 이름에 포함하며, 내부 sentence ID는 화면에 표시하지 않는다.
- `FeedbackPanel`: 판정 상태의 한국어 이름·메시지·근거 문장을 한 묶음으로 보여 준다.
