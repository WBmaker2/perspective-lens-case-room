# 교육용 웹앱 리디자인 자산 검토

검토일: 2026-08-30 (KST)

## 검토 범위

리디자인 중 화면의 맥락을 바꾸거나 학습자의 주의를 분산시킬 수 있는 이미지 자산만 확인했습니다. 검색 대상은 `src/`, `public/`, `index.html`의 이미지 태그, SVG, CSS 배경, `url()`, `srcset`입니다.

## 기존 자산과 결정

| 경로 | 역할 | 표시 방식 | 결정과 근거 |
| --- | --- | --- | --- |
| `src/components/CaseIllustration.tsx` | 네 허구 사건의 장소·물건을 빠르게 떠올리는 학습 보조 그림 | `viewBox="0 0 320 190"` 인라인 SVG, `role="img"`, 사건별 `<title>` | 유지합니다. 사건 콘텐츠와 1:1로 연결되고, 선·색이 기존 라이트 팔레트와 일치하며 외부 요청이 없습니다. |
| `public/favicon.svg` | 브라우저 탭의 앱 식별 | `index.html`의 `./favicon.svg` 상대 경로 | 유지합니다. GitHub Pages 하위 경로에서 동작하는 기존 식별 자산이며 학습 화면의 읽기 폭에 영향을 주지 않습니다. |

## 검색 결과

- React 화면에는 `<img>`, `srcset`, CSS `background-image`, 외부 이미지 `url()`이 없습니다.
- 외부 폰트·이미지 요청을 추가하지 않았습니다.
- 사건 그림은 CSS 크기 `width: min(100%, 25rem)`으로 좁은 화면에서도 컨테이너 안에 맞춰집니다.
- 정적 PNG는 QA 증거 문서용이며 학습 화면의 콘텐츠 자산으로 재사용하지 않습니다.

## 생성·교체 안전 판정

학습 화면에 사실·지도·차트·스크린샷 또는 실제 인물을 묘사하는 이미지 후보는 없습니다. 화면 자산은 기존 인라인 SVG와 파비콘을 유지했습니다. 시각 방향 검토를 위해 이미지 생성 모델로 `.impeccable/mocks/perspective-lens-comp-stage-rail.png`와 두 대안을 만들었지만, 이 파일들은 북극성 comp·프롬프트 sidecar인 비배포 참고 자료이며 학습 화면의 콘텐츠나 UI를 대체하지 않습니다. 리디자인 구현은 텍스트 위계, 상태 안내, 카드 표면, 반응형 배치에 한정했습니다.

## 검증 기준

- 각 SVG의 대체 이름은 사건 제목을 담은 `<title>`과 `aria-labelledby`로 제공됩니다.
- 375px에서 그림이 카드·고정 도구·현재 행동 버튼을 밀어내거나 가로 스크롤을 만들지 않아야 합니다.
- 자산 변경이 없으므로 이미지 라이선스·출처·압축 파일을 새로 추가할 필요가 없습니다.
- 생성 comp에는 `.png.json` sidecar로 prompt와 승인 방향 `99fd868c`를 기록했고, 실제 배포 bundle에는 포함하지 않습니다.
