# Elementary Learner UX Audit

## 점검 범위

- 날짜: 2026-08-30 KST
- 모드: `full`
- 주 페르소나: 서윤(초등 5–6학년, 10–12세)
- 보조 페르소나: 준호(초등 3–4학년, 8–10세)
- 확인 뷰포트: 320×800, 375×812, 640×900, 761×900, 1280×900
- 학습 경로: 사건 접수 → 렌즈 A/B → 근거 보드 → 교차 조사(처음 생각) → 추가 기록 → 수정 비교 → 관점 전환 → 사건 보고서
- 사용한 브라우저: Codex in-app browser, 로컬 Vite 서버 `http://localhost:4174/`
- 음성·VoiceOver·실제 학생·교실 수용성 평가는 실행하지 않았습니다.

## 사전 준비

`work/elementary-webapp-ux-bootstrap.md`의 Stage 0 결과는 `ready`였습니다. 프로젝트 규칙과 기존 설계·리디자인 문서를 읽었으며, 새 패키지 설치나 설정 변경은 하지 않았습니다.

## 학습자 언어·행동 점검

- 목적: 첫 화면과 `현재 단계 1/6`이 활동 목적과 다음 행동을 함께 말합니다.
- 행동: `사건 선택`, `읽음 표시`, `중요 문장 표시`, `근거 표시하기`, `교차 조사 시작`, `관점 전환 완료`가 실제 조작 대상과 일치합니다.
- 대상: 사건·문장·근거·블록이 버튼/라디오/체크박스의 이름에 함께 노출됩니다.
- 결과: 성공·부분·다시 살펴보기 피드백과 `분류 완료 n / 10` 진행 상태가 `role=status`로 전달됩니다.
- 회복: 잘못된 근거 분류 후 같은 카드에서 범주를 고쳐 다시 제출할 수 있고, 피드백 영역으로 포커스가 이동합니다.
- 전이: 각 단계의 활성 CTA만 `gi-pulse`를 사용하고, 보고서에는 `오늘 배운 점`과 `다음에 해 볼 일`이 있습니다.
- 내부 용어: 화면에 내부 사건 ID, 디버그 상태, 점수·승자 표현이 노출되지 않았습니다.
- 개인정보: 사건과 인물은 가상이며 세션·메모·읽기 설정만 기기에 저장되고 외부 전송이 없습니다.

## 구현한 개선

### EDU-UX-001 해결

1. `src/styles/layout.css`의 `@media (min-width: 761px)`에 `padding-top: 5.75rem`을 추가해 고정 학습 도구를 위한 상단 안전 공간을 확보했습니다.
2. `@media (min-width: 761px) and (max-width: 1024px)`에서 `app-shell__topbar`를 한 열로 바꾸고, 사건·첫 생각 카드를 두 열, 선택된 사건 작업 공간을 한 열로 배치했습니다.
3. `tests/e2e/accessibility.spec.ts`에 761×900 사각형 교차·카드 행 수·가로 오버플로 회귀 검사를 추가했습니다.
4. `src/content/updateHistory.ts`에 2026-08-30 개선 기록을 추가하고 `src/content/updateHistory.test.ts`, `src/features/updates/UpdateHistoryDialog.test.tsx`의 행 수 검사를 갱신했습니다.

### EDU-UX-002 관찰 후속

핵심 CTA는 기존 `StageActionButton`의 겹침 감지와 중앙 스크롤로 보호되고, 보고서 마지막 CTA는 375×812에서 도구 위에 남습니다. 본문 위에 떠 있는 도구 자체는 P2 후속 관찰로 남겼으며, 이번 범위에서 새 음성 기능·추적·콘텐츠 로직 변경은 하지 않았습니다.

## 최종 브라우저 증거

- 761×900: `.utility-group` bottom 73.2px, `.progress` top 162.4px, 교차 `false`, 사건 카드 행 수 `2`, `scrollWidth === clientWidth`.
- 1280×900: `.utility-group` bottom 73.2px, `.progress` top 107.6px, 교차 `false`, 사건 카드 행 수 `1`.
- 375×812: 전체 학습 경로를 다시 완료하고 최종 heading `사건 보고서`, 가로 오버플로 `false`, 최종 `gi-pulse` 수 `0`을 확인했습니다.
- 320×800·640×900: 가로 오버플로 `false`를 확인했습니다. 모바일 도구는 하단에 있고 본문 하단 예약 공간을 사용합니다.
- 브라우저 콘솔: 오류·경고 `[]`.
- 모달: 업데이트 내역과 reset 대화상자를 열고 Escape로 닫은 뒤 각 trigger로 포커스가 돌아오는 것을 확인했습니다.
