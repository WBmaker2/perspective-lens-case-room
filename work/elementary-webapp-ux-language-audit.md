## 표현 일관성 확인

- 판정 키 `observation`, `inference`, `evaluation`과 화면 label `관찰 사실`, `인물의 추론`, `평가 표현`은 `evidenceCategoryGuidance`에서 함께 관리합니다.
- 비교 키 `sharedFactOptionIds`, `differentExpressionOptionIds`, `missingInformationOptionIds`와 화면 설명은 `comparisonCategoryGuidance`에서 함께 관리합니다.
- `문장 조각`은 관점 전환 화면·접근 가능한 이름·알 수 없는 ID fallback에서 같은 낱말을 사용합니다.
- `사실만 적힌 기록`은 목록 label, item accessible name, 추가 기록 상태 안내에서 같은 낱말을 사용합니다.
- 내부 ID, 점수, 승자, 정답률, 시뮬레이션 모델 용어는 학습자 화면에 추가하지 않았습니다.

## 시각·접근성 확인

- 기존 라이트 테마, `gi-pulse`, `prefers-reduced-motion: reduce`, 44×44px 조작 영역, 키보드 순서를 변경하지 않았습니다.
- 설명은 `.supporting-copy`를 재사용하여 기존 색 대비·줄 간격 토큰을 따릅니다. 새 이미지나 색상 의미를 추가하지 않았습니다.
- `aria-label`, `legend`, `role=status`, `aria-live="polite"`가 새 학습자 표현과 일치합니다.
- VoiceOver는 사용하지 않았으며, 화면 낭독에 필요한 DOM 이름·상태만 단위 테스트와 in-app browser로 확인했습니다.
